DMX Lighting Fixture Install

Installation of flat parcan lighting fixures in a fixed multi-purpose hall.

Overview

This was an install project that I had assisted in, to rig lighting fixtures run cables and set-up the system.

Process

It began with running cables from the respective locations, of AVL equipments, to the FOH (AV rack) over the celiling on cable trays. After which came the rigging of lighting fixtures and cabling it all up. After that, I assigned the respective fixtures' DMX addresses and tested them.

Outcome

The ligthing fixtures were grouped by assigning matching dmx addresses to inner - outer pairs of fixtures. This was done as the lighting console that we were using was a cheap analog mixer that had limited individual DMX addressing control, hence to simplify the set-up for sapce users, this was the step taken.

Project Info

Role: Lighting Fixture Rigger

Tools: Flat parcan Fixture, DMX512 Analog Console
